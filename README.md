# Proxylity Agent Skills

Portable [Agent Skills](https://agentskills.io/) for building with [Proxylity](https://proxylity.com) services on AWS. Compatible with GitHub Copilot, Claude Code, Cursor, Gemini CLI, and [other agents](https://agentskills.io/#clients).

## Skills

| Skill | Description |
|---|---|
| [udp-gateway](skills/udp-gateway/) | Design, implement, deploy, and troubleshoot Proxylity UDP Gateway solutions on AWS |

## Kiro Power

The repository root is also an [Agent Plugin](https://agent-plugins.org/) (`plugin.json`) and installs as a Kiro Power. In Kiro, open Powers, choose **Add Custom Power**, and enter this repository's URL or a local clone.
