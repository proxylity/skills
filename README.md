# Proxylity Agent Skills

Portable [Agent Skills](https://agentskills.io/) for building with [Proxylity](https://proxylity.com) services on AWS. Compatible with GitHub Copilot, Claude Code, Cursor, Gemini CLI, and [other agents](https://agentskills.io/#clients).

## Skills

| Skill | Description |
|---|---|
| [udp-gateway](udp-gateway/) | Design, implement, deploy, and troubleshoot Proxylity UDP Gateway solutions on AWS |
